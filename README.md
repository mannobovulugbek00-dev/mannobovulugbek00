"Territory War" — bu to'rtta jamoa o'rtasida kechadigan qiziqarli strategik brauzer o'yini. Har bir jamoa xaritaning burchaklaridan 8 tadan hudud bilan boshlaydi. Qolgan joylar neytral (kulrang). Navbat bilan spin qilib (1-7 ochko), qo'shni hududlarni egallaysiz va oxirida barcha raqiblarni yengib, xaritada yolg'iz qolishga harakat qilasiz!
